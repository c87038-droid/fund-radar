我的基金雷達｜免費雲端自動更新版（7 檔基金）
====================================

一、這個版本做得到什麼？
- 同一個網址，手機/電腦都能看 7 檔基金和配息。
- 開啟網頁時，會重新下載最新的雲端資料檔，避免使用舊快取。
- GitHub Actions 每天臺灣時間 09:15、18:15、23:15 嘗試抓公開資料，並自動重新發布網頁。
- 資料來源：境外基金為集保 TDCC 公開 CSV，境內淨值為投信投顧公會 SITCA 每日 CSV；境內配息為 SITCA 境內基金配息資料。
- 顯示基金真正的「淨值日期」和「雲端最後檢查時間」，資料源失敗時保留舊值、標示同步異常，不把快照稱為新行情。
- 自行新增的其他基金不會自動對應，需要另外加入基金 ISIN 和來源設定。

二、建立公開網址（全程可以免費）
1. 前往 https://github.com/ ，註冊或登入免費帳號。
2. 右上角按 + > New repository，Repository name 填：fund-radar。
   請選 Public（公開），點 Create repository。
3. 在你電腦先將本 ZIP 解壓縮，再將 fund-radar-cloud 資料夾內的所有內容
   （index.html、data、scripts、.github、.nojekyll 等）上傳到儲存庫根目錄。
   GitHub 網頁上可使用 Add file > Upload files，將檔案/資料夾拖入上傳區，
   確認 .github/workflows/update-and-deploy.yml 等子資料夾結構沒有遺失。
   如網頁不允許上傳整個資料夾，可改用 GitHub Desktop：
   https://desktop.github.com/ 把檔案放入本地儲存庫，按 Commit 和 Push。
   【注意】不要只把 ZIP 當成單一檔案上傳。網站需有根目錄的 index.html。
4. 進入 GitHub 專案的 Settings > Pages，將 Source 設為 GitHub Actions。
   如沒有看到部署設定，請先確認倉庫為 Public 且主分支名稱為 main。
5. 點上方 Actions >「基金淨值與配息自動更新」> Run workflow > Run workflow。
   第一次成功發布後，Settings > Pages 會看到網站網址。
6. 網址通常是 https://你的GitHub帳號.github.io/fund-radar/
   這個網址可以貼到 LINE 傳給自己，或加入手機桌面。

三、電腦與手機怎麼開？
- 電腦：用 Chrome / Edge 開啟同一個 GitHub Pages 網址，可加到書籤。
- iPhone：用 Safari 開啟同一網址，點「分享」>「加入主畫面」。
- Android：用 Chrome 開啟，點右上選單 >「加到主畫面」。
- 這是響應式版型；手機較寬的基金表格可左右滑動，不必另外安裝 App。
- 電腦與手機都會看到同一批「雲端已發布」的淨值和配息資料；個人輸入的持有單位數
  僅保存在各自裝置，不會自動同步。

四、更新機制注意事項
- 開啟網址時只會重新讀取「最後一次成功發布的官方資料」，不會立即抓取政府網站。
- GitHub 排程可能延遲；官方基金淨值也可能晚一天至數天公布，假日沒有新淨值。
- 可到 Actions 手動按 Run workflow 立即再嘗試抓取（是否成功依來源網站而定）。
- 某些官方來源可能防爬、改版或暫時關閉，該檔會保留上次資料並顯示其日期。
- 建好後請在 Actions 頁確認「資料同步成功」，並核對各基金最新日期。
- 2026/11/06 的歷史快照僅供第一次畫面展示，並不是即時資料。

六、重要隱私與配息提醒
- GitHub Pages 公開網址不是私人網站，任何取得網址的人都可能看到這7檔觀察基金。
- 網頁自填的「持有單位數」只會存放在你當下使用的瀏覽器 localStorage；
  不會上傳 GitHub，也不會跨電腦/手機自動同步。請定期按「匯出備份」。
- 不要把有持有單位數的個人備份 JSON 放上公開的 GitHub 儲存庫。
- 各基金可能有來自本金的配息，配息率不等於總報酬率。

七、狀態驗證
- GitHub Actions 第一次執行完成後，打開網站的頂部「雲端資料」狀態。
- 若顯示尚無更新，請至 Actions 內檢視來源錯誤；公開資料來源偶爾會變動。
- 在公開網址開啟前，單純雙擊 index.html 會因瀏覽器的本機存取限制而無法讀取雲端資料。
- 公開來源是否能成功匹配全部 7 檔仍須在第一次雲端執行時逐檔驗證。
