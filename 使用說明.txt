我的基金雷達｜預估配息／匯率按鈕錯誤修復

問題原因：GitHub 目前的 update-and-deploy.yml 僅將 index.html 複製到 _site，沒有將 estimate.html、fx.html 放入 GitHub Pages 網站發布檔。
此版將三個頁面一起發布，並保留 data/live.json 和存在的 favicon 圖示。

這次只需更新一個檔案：
.github/workflows/update-and-deploy.yml

操作方式：
1. 打開 https://github.com/c87038-droid/fund-radar/blob/main/.github/workflows/update-and-deploy.yml
2. 點鉛筆（Edit）編輯，將完整內容替換成此 ZIP 中同名的 YAML，按 Commit changes。
3. 進入 https://github.com/c87038-droid/fund-radar/actions ，選擇最新「我的基金雷達｜基金自動更新與發布」紀錄。
4. 確認所有步驟成功後，開啟以下連結測試（建議無痕視窗）：
   基金首頁：https://c87038-droid.github.io/fund-radar/
   配息試算：https://c87038-droid.github.io/fund-radar/estimate.html
   匯率查詢：https://c87038-droid.github.io/fund-radar/fx.html

注意：
- estimate.html 與 fx.html 已存在於目前 GitHub 儲存庫根目錄，無須重複上傳。
- 新的 YAML 不變更基金計算、基金數量及前端頁面。
- 如果部署工作回報 No artifacts named github-pages，表示部署服務或 artifact 階段另有問題，請提供新執行紀錄；不等於此次 404 修正無效。
- GitHub Pages 發布後可能需要短暫時間更新 CDN；如果仍出現舊頁面，請用無痕視窗檢查。
