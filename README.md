# 我的基金雷達｜7 檔共同基金專用

**只追蹤基金淨值與配息，不是台股 Top 50 或股票報價程式。**

- 先依計價幣別分組：**美元 USD（6 檔）在前、南非幣 ZAR（1 檔）在後**。
- 每一幣別下，**同一家基金公司集中顯示**：安聯 → 摩根 → 瀚亞 → 聯博；其後是東方匯理南非幣。
- 點基金可看淨值日期、每單位配息、除息日、發放日和歷史配息紀錄。
- 資料來自臺灣集中保管結算所公開的境外基金開放資料（3-2 基本、3-4 淨值、3-5 配息），以及投信投顧公會境內基金每日淨值、配息資料。
- GitHub Actions 預定在**臺灣時間每天 09:15、18:15、23:15**嘗試同步並部署。實際可能因排程延遲、基金公告晚於排程或公開資料異常而不即時。
- 首次上傳後資料欄為「尚無資料」是正常的。必須先執行同步，且來源有發布，才會顯示數值；不會捏造數字。
